## Notes

Collector runs under `SQUALL\jmay2` with Interactive Task Scheduler logon type; it starts at **sign-in**, not before. The launcher originally contained an absolute SQUALL path; feature-branch correction now uses `WScript.ScriptFullName` to resolve the collector relative to the launcher. **That particular path-portability change requires one local pull and quick launch regression test before sign-off**. Logon/reboot evidence predates the path portability correction, but fully validates the earlier hidden launcher.

## Not yet proven

- Actual live Pi USB DHCP *address reassignment* (dispatcher same-address no-op and USB adapter interruption tested).
- Extended endurance, SD-write wear, graceful interruption/forced-stop logging.
- Recovery after invalid/revoked credentials, loss of DPAPI user context, noninteractive login before sign-in.
- Security against a compromised host or any additional peers on the USB segment; HTTP offers no encryption.
- Complete repository-wide secret scanning and independent installation from a fresh device.
