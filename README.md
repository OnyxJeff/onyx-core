# ONYX CORE

A version-controlled, USB-connected telemetry and companion platform
running on Raspberry Pi Zero Rev 1.3.

## Status
Phase 0 — Project initialization.

## Development principles
- GitHub is the source of truth.
- Deployments are reproducible.
- No secrets are committed.
- Each milestone requires validation.
- Releases identify tested configurations.

## Hardware
- Raspberry Pi Zero Rev 1.3
- 32GB microSD
- USB connection to Windows 11 host SQUALL
