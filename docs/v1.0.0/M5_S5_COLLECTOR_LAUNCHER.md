# M5-S5 collector startup correction

The direct PowerShell action started at logon but exited with 0xC000013A after an operator reported closing a console. The gateway stayed running. This supports, but does not independently reproduce, a console-control termination. Windows kernel boot time was unchanged; full reboot remains unqualified.

The S5 Windows candidate is a deterministic derivative of the exact accepted S2B Windows ZIP. Its existing M4 source identity is retained and its manifest additionally identifies the parent archive and new launcher source. Only the collector lifecycle admission and launcher payload differ; gateway, Pi, credentials, configuration and telemetry logic are not changed. The historical package remains valid and is retained for rollback. The S5 artifact contains 25 payload files. Its native publication and task action handover are separate gates.

The scheduled action must use the full system wscript.exe path, //B //Nologo, the adjacent Launch-OnyxTelemetry.vbs and the existing reviewed collector argument suffix (not the PowerShell host arguments). The wrapper passes -RequireLauncher, uses a fully qualified PowerShell executable, hidden synchronous Run and propagates exit code. The optional new collector guard requires the existing parent detection to succeed when the flag is present. It does not read a token before this check. Arguments containing quotes, percent expansion, control characters or trailing backslashes are refused. Do not supply secrets as arguments.

Native gates: WScript availability, argument forwarding with a no-network fixture, parent identity, exit code, actual collector startup and fresh telemetry, controlled task stop without orphan process, logon/reboot with no visible collector window. VBScript availability is a platform dependency; no enabling optional features or policy changes are approved. No native fixture result implies full lifecycle acceptance. Final release tooling must incorporate this derivative (or consolidate its changes into the final committed builder) and preserve the actual CPU sensor and USB address settings.
